# Distrito Barber — landing page de demostración

Landing page responsive para una barbería ficticia, desarrollada como proyecto de portfolio por **Gonzalo Martínez**.

## Características
- Diseño editorial oscuro con acentos verde lima.
- Secciones de servicios, propuesta de valor y contacto.
- Navegación por anclas y estilos adaptables a móviles.
- Elementos semánticos, enlace para saltar al contenido y respeto por preferencias de movimiento reducido.
- Sin dependencias externas ni cookies.

## Ejecutar
Abrí `index.html` en el navegador. No requiere instalación.

## Tecnologías
HTML5 y CSS3.

## Importante
**Proyecto ficticio / demostración.** Los servicios y la marca son ilustrativos. No existen reservas ni cobros reales. El botón final enlaza al WhatsApp de Gonzalo Martínez para consultas sobre desarrollo web, no a una barbería.
